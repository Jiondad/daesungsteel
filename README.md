# 대성스틸 온실가스 인벤토리 시스템

Scope 1(경유·도시가스)·Scope 2(구매전력) 배출량 관리, 목표 대비 실적 대시보드, 감축 로드맵 시뮬레이터.
(Scope 3는 산정 대상에서 제외, 수도 사용량은 참고 지표)

## 폴더 구조

```
src/
  lib/            계산 로직(순수 함수 — 테스트 대상)
    constants.js    연도별 배출계수, KPI·로드맵 목표, 설정값(GOOGLE_WEBAPP_URL)
    emissions.js    배출량 계산, 입력 여부 판단, 숫자 표시
    planning.js     계절 프로파일, 연간 계획 자동 수립, 연말 예상(연환산)
    roadmap.js      로드맵 시나리오 계산
    period.js       선택 기간 집계(입력된 달까지만 목표 누적), 달성률
    chartData.js    그래프용 월별·누적 데이터
    audit.js        감사 보고서 데이터, 변경 이력, 데이터 품질 점검, 엑셀 시트 구성
    exportWorkbook.js  엑셀(.xlsx)·JSON 내보내기 (엑셀 라이브러리는 내보내기 시에만 로드)
  services/
    db.js           Google Apps Script(구글 시트 A1) 저장·불러오기
  components/       화면(Dashboard, DataEntry, TargetSetting, Roadmap, AuditReport, YearPicker, 차트 등)
  App.jsx           상태 관리, 탭, 저장/불러오기 흐름
tests/              단위 테스트(lib)와 화면 시나리오 테스트(app)
.github/workflows/  테스트 → 빌드 → GitHub Pages 배포
```

## 감사 대응 기능

- **감사 보고서 탭**(관리자 인증 필요): 보고 개요·경계, 배출량 요약, 월별 산정표, 산정 방법·배출계수(출처), 목표 수립 기록, 로드맵 시나리오, 데이터 품질 점검, 변경 이력을 한 문서로 생성
  - **인쇄 / PDF 저장**: 브라우저 인쇄 창에서 "PDF로 저장"
  - **엑셀 내보내기**: 요약, 월별 산정표, 배출계수·방법, 목표 대비, 데이터 품질, 변경 이력(+시나리오) 시트
  - **전체 데이터 백업(JSON)**: 실적·목표·설정·시나리오·변경 이력 전체
- **보고서 설정**(조직경계, 배출계수 출처, Scope 3 제외 사유, 결재자)은 DB에 저장되며, 미기재 항목은 보고서에 붉게 표시됩니다.
- **변경 이력**: 실적·목표·연도·설정·시나리오를 저장할 때마다 작업, 내용(변경된 값), 작업자를 기록합니다.
  현재는 브라우저에서 기록하는 내부 이력이며 서버 인증 기반의 변조 방지 이력이 아닙니다(보안 단계에서 개선 예정).
- **로드맵 시나리오**: 가정·근거·연도별 결과를 이름을 붙여 저장하고(최대 20개) 보고서에 포함할 수 있습니다.

## 서버(Apps Script) 보안·저장 구조

- 데이터는 구글 시트에 **표 구조**(실적·목표·변경 이력·백업 등)로 저장됩니다. 설치 방법은 [`apps-script/README.md`](apps-script/README.md) 를 참고하세요.
- 관리자 로그인은 **서버에서 비밀번호를 확인**합니다(화면 코드에 비밀번호 없음). 저장 시 동시 저장 충돌 방지, 입력 검증, 월 마감, 서버 변경 이력(작업자·변경 전→후 값), 자동 백업이 적용됩니다.
- 서버 코드는 `apps-script/Code.gs`, 화면은 `src/services/db.js` 를 통해서만 서버와 통신합니다.
- 서버 규칙은 `tests/apps-script/` 의 테스트가 가짜 스프레드시트 위에서 실제 코드를 실행해 검증합니다.

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm test         # 계산 로직·화면 시나리오 테스트
npm run build    # dist/ 생성
```

## 배포 (GitHub Pages)

1. 저장소 Settings → Pages → Source 를 **GitHub Actions** 로 설정
2. `main` 브랜치에 push 하면 테스트가 통과한 경우에만 자동 배포

> 빌드는 상대 경로(`base: './'`)라 저장소 하위 경로나 사내 웹서버 어디에 올려도 동작합니다.
> 테스트가 실패하면 배포되지 않으므로, 계산식이 의도치 않게 바뀌는 것을 막아 줍니다.

## 수정 시 주의

- **배출계수**: `src/lib/constants.js` 의 `EMISSION_FACTORS_BY_YEAR` 에서 연도별로 관리합니다.
  현재 2024~2026 값이 동일하므로, 연도별 공식 고시값과 출처를 확인해 교체하세요.
- **공식 감축 목표**: `ROADMAP_TARGETS` (2025 기준 579.116 tCO₂e).
- **저장소 주소**: `GOOGLE_WEBAPP_URL` (Apps Script 웹앱).
- 계산 로직을 바꾸면 `npm test` 로 기준값(2025 = 579.116 tCO₂e 등)이 유지되는지 확인하세요.
